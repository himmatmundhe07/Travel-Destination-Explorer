# Travel Destination Explorer

A Next.js App Router project exploring global destinations, nested regional hierarchies, and transit networks.

## Features
- Dynamic destination routing with detailed cartographic and transit overviews.
- Nested and catch-all region explorer (`/regions` and `/regions/[...slug]`).
- Trip planner workspace overview with draft routes and saved nodes.
- Custom 404 unresolved destination fallback page.

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
